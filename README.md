# Sumhaven 1.0 TEST
Native Java/Canvas Android 8+ Rekuto side-sum rectangle partition puzzle.

Tap two opposite corners to draw a rectangle. Cover every tile without overlaps. Each rectangle contains exactly one clue, equal to its width plus height in cells. Squares and one-cell-wide strips are allowed. This is not area or full perimeter: a 2 by 3 rectangle needs 5. Twelve unique 4x4 clue boards have twelve distinct rectangle partitions.

Saved plot palette and rectangle labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate-set oracle tests all 100 possible rectangles per board against the production side-length formula, then set-based exact-cover search proves one partition each. Bounds, overlap, empty-cover, drawing, solve, undo and replay checks pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 106 recovered READMEs and recent cumulative stages/releases found no Rekuto match. Shares Willowcourt and Mosaicmeadow rectangle placement, but width-plus-height clues replace clue-cell boundary touches or rectangle area. Candidate geometry and exact-cover solutions therefore differ. Known Rekuto genre, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed.
